# 知识型视频结构化文档生成系统

将教学视频、演讲报告和科普讲解转换为结构清晰的图文讲义，帮助读者按章节回顾内容、定位知识点，并保存为便于阅读和分享的文档。

## 适用场景

- 课程复习：把视频课程整理成带章节和配图的学习资料。
- 演讲回顾：整理报告与演讲的主题结构、核心内容和时间位置。
- 科普阅读：将解说和画面组织成便于阅读的图文资料。
- 知识整理：从讲座、报告和科普视频中提取结构化内容。
- 内容复用：将视频中的讲解与代表画面组织成可编辑、可检索的数据和文档。

## 核心能力

| 能力 | 说明 |
|---|---|
| 语音转写 | 提取音频并生成带时间戳的ASR文本 |
| 画面与文字提取 | 采样视频帧、检测页面变化、识别画面中的文字 |
| 时间轴组织 | 按时间关联转写、画面和OCR信息 |
| 章节划分 | 通过文本LLM生成章节边界与标题 |
| 图文讲义生成 | 组织全文概述、章内正文、章节配图和结论 |
| 多格式导出 | 输出JSON、Markdown和内嵌图片的Word文档 |
| 任务与结果管理 | 保存来源引用、生成记录和版本化结果，复用已有缓存 |

## 处理流程

```text
本地视频
  ├─ 音频提取 → 语音转写
  └─ 视频抽帧 → 页面变化 → OCR
                 ↓
              统一时间轴
                 ↓
             章节划分与配图
                 ↓
               正文生成
                 ↓
         JSON / Markdown / Word
```

语音转写提供讲解内容，画面与OCR提供页面信息和配图线索。系统将这些来源与时间位置关联，再组织章节和讲义内容。

## 输出内容

一份讲义包含标题、全文概述、章节正文、代表画面与说明、时间位置和全文结论。JSON保留结构和来源信息，Markdown便于阅读和二次处理，Word便于排版、打印和分享。

每个任务使用独立目录保存中间结果和导出文件，便于继续处理已有任务或查看生成记录。

## 技术组成

项目使用Python实现，结合FFmpeg、Whisper语音识别、RapidOCR、文本LLM和python-docx完成视频处理与文档生成。模型角色和连接参数通过配置文件管理。
