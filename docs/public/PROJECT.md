# 项目总览

本项目将教学视频、在线课程和知识讲解整理成带章节、正文、配图及时间位置的讲义，支持JSON、Markdown和Word导出。主要使用场景是带PPT的中文课程。

项目立项名称为“基于多模态信息融合与强化学习决策的知识型视频结构化文档生成系统”。当前以可用软件交付为主，强化学习保留为独立探索，尚未实现。

## 当前能做什么

现有命令行流程可以检查视频、提取音频、进行ASR转写、抽帧、检测页面变化、运行可选OCR、建立统一时间轴，再调用文本LLM完成分章和正文生成，最后选配章节图片并导出讲义。

ASR负责识别语音，OCR负责识别画面文字。分章和正文模型主要读取ASR文本；当前配图说明由页面变化和OCR信息生成。直接读取图片的VLM模式尚未接入。

已有DEV01、COURSE01、LONG01、EXPLAINER01四个真实视频案例。最近完成引用约束修复和EXPLAINER01真实生成验收，部分结果另外制作了离线审校版。原始视频及内部产物由负责人保存，仓库提供合成示例供开发使用。

目前没有Web界面、应用内编辑、规则分章或PPO模块。自动正文还会出现ASR错词和事实关系混淆；讲义用于正式展示前需要内容检查。离线审校文件与模型原始输出分别保存。
