# 中期检查支线任务计划

更新：2026-11-04。适用对象：项目组成员及承担本任务的协作者。

## 目标

中期前完成正式软件主流程所需的整套操作界面，整理可直接放进PPT的真实成果素材。中期预计以PPT展示为主，本任务不要求现场演示或录屏。

本计划规定目标和交付要求。承担者自行选择实现方式、拆分工作和安排进度。任务归属A3中期准备，其中开发成果对应A5，后续主线可直接复用。

## 功能范围

| 功能 | 预期结果 |
|---|---|
| 视频输入与任务创建 | 导入或选择本地视频，建立任务，展示基本视频信息 |
| 生成与任务管理 | 从页面启动现有生成流程，查看任务列表、当前阶段、完成结果和错误信息，重新打开已有任务 |
| 图文结果预览 | 查看标题、章节、正文、配图和时间位置，切换结果版本 |
| 基础编辑 | 修改文档/章节标题和正文，删除不合适配图 |
| 版本保存 | 保存并重新打开编辑结果，区分机器原始结果与编辑版本，追溯来源 |
| 导出与下载 | 将所选版本导出为Word、Markdown、JSON，主要文本和图片集合一致，可从页面下载 |
| 界面完整性 | 页面导航、布局、长内容显示、加载/空状态、错误反馈和操作提示统一，主要流程能连续使用 |

生成入口接现有视频处理链，结果页与编辑导出复用现有能力，原机器正式组及其current保持不变。界面与存储设计由承担者决定，兼容现有CLI和结果格式。可以先阅读[开发指南](DEVELOPMENT.md)与[合成数据示例](../examples/README.md)。

## PPT素材

- **两条案例**：至少一条中文课程，另一条体现补充场景或处理难点。包含输入说明、章节结构、图文讲义和导出页面。
- **完整数据链**：主案例展示同一任务的视频代表帧、带时间的ASR、适用时的OCR、分章与最终讲义。
- **功能截图**：真实运行的视频输入、任务状态、图文预览、编辑及导出页面；选一个有实际意义的修改展示前后对照。
- **技术与进度说明**：实际架构图、处理流程图、功能完成情况、已知问题。已有日志支持时列出时长、章数、配图数、耗时和请求数；未记录的字段留明。
- **素材索引**：为图片和文档标明任务、版本、文件位置及简短说明，方便后续组装PPT。

自动生成结果与编辑成果分开标识，截图对应实际功能。PPT文件本身可以在素材交付后另行制作。

## 数据与开发起点

公开仓库不附带真实视频、内部响应和生成产物。负责人协调可分享的案例；成员也可使用有权使用的素材。

功能开发可先运行`python tools/demo_offline.py`获得完整合成任务及导出包，无需真实视频、模型权重或API Key。合成输入用于功能检查，PPT案例使用明确标识来源的真实材料。真实API调用另行确定范围和有限预算。

## 分支与交付

从执行时公开仓库最新main创建独立功能分支，可在个人Fork中开发。提交时提供：

1. 分支地址、基线提交、最终提交及改动摘要。
2. 功能运行说明、必要依赖和配置，以及接口/编辑版本的简要说明。
3. 直接相关的功能检查记录、已知问题和未完成项。
4. 两条案例、截图、技术图、导出文件和素材索引。

修改先保留在功能分支，由负责人决定是否合并。实现方法和内部任务安排由承担者负责，涉及既有冻结契约或核心路线变更时先沟通。代码、说明和可公开的小型素材放仓库，真实视频、密钥和大体积产物通过约定方式共享。

## 完成标准

- 从视频输入、新建任务、启动生成、查看状态到图文预览、编辑保存和导出下载，主流程在同一套界面中可操作。
- 已有任务和结果可重新打开，长任务执行过程可查看阶段，正常、加载、空状态及错误情况都有相应展示。
- 机器原始组保留，修改可追溯，导出内容跟随选定版本。
- 两条案例和功能截图来源清楚、内容可读，能够直接支持PPT展示。
- 技术说明与代码和产物一致，完成项、缺项和检查范围记录清楚。

新增功能只做直接必要的检查，例如编辑保存、重新打开、选定版本导出和删图一致性。本任务不安排安装专项、跨机器复现、稳定性/压力测试，也不要求现场连续操作。

## 后续衔接

本任务聚焦本机单用户的完整主流程界面。VLM/RL、15视频扩充、复杂富文本、账号、云部署和多人协作留后续工作。

中期结束后，负责人评估分支并决定全部、部分合并或继续修改。A5的主要界面功能在本支线完成并按验收结果登记，中期后保留同一套界面，主要接入VLM等增强能力，不重复建设基础操作流程。案例和素材继续用于A6系统检查及A7说明书、软著材料。
