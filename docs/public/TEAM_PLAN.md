# 团队执行计划与当前任务

更新：2026-11-04。统一使用A0—A7阶段；A0—A2完成，下一阶段A3。

## 一、团队共同目标

2027年1月交付功能完整、可安装、可演示的视频讲义生成软件，完成软著材料准备。核心流程为：导入视频→查看状态→预览图文讲义→按余量支持基础修改→导出Word/Markdown/JSON。

重点场景是带PPT的中文课程；其他场景保留为扩展测试。先保证系统可用，再有限验证视觉模型，RL作为独立探索。正式大创题目暂不改变，负责人确认结项口径；主软件无需等待PPO完成。

**详细技术范围、验收、停止条件和排期见[1月交付方案](DELIVERY_PLAN.md)。** 本文件供认领任务；新增能力的设计与验收以交付方案为准，任务进度通过Issue/PR更新。

## 五、可独立认领的团队任务

| 任务 | 交付与验收 |
|---|---|
| 第二台机器安装 | 系统/Python版本、命令及截图，按README完成零API演示，问题可复现 |
| 文档质量检查 | 问题表关联视频时间和文档位置，检查事实/遗漏/配图/排版；LONG01已检查，新增文档按版本检查 |
| 视频核验 | 来源、场景、时长、音画质量与使用范围，清单去重可追溯 |

| 普通缺陷 | 最小复现、有限修复与相关测试，PR说明未验证项 |

任务不预先分配到个人。核心生成链由一名主负责人统筹，其余成员可并行做检查和材料；避免多人同时改同一核心模块。真实视频、密钥、模型和大体积outputs不提交Git。

Fork后先开Issue说明范围、交付物和验收，再在功能分支工作并提交PR。真实API或图像外发须先获得范围和有限预算授权；本次计划调整不产生调用授权。RL只按实际完成的训练、推理、接入记录汇报，未完成不阻塞软件。
