# 软件交付计划

更新：2026-11-04。目标：2027年1月完成可使用的视频讲义软件和软著材料准备。

## 交付范围

最终软件支持视频输入、任务状态、章节图文预览、Word/Markdown/JSON下载，并提供基础内容修改能力。已有ASR、抽帧、OCR、分章和导出链继续复用，重点场景为带PPT的中文课程。

VLM作为有限增强，使用现成模型读取章内少量图片与ASR，优先验证其是否补充有用的图表、公式或代码信息。保留ASR路径。规则、数据标注和PPO为独立探索，不阻塞软件交付。

## 当前中期支线

当前先完成[中期检查支线任务](MIDTERM_BRANCH_PLAN.md)：完整主流程界面，包括视频输入、任务创建与生成、状态查看、图文预览、基础编辑、版本保存、导出下载，并整理两条案例、关键技术设计、修复与质量分析及PPT素材。任务面向组员，在独立分支中实现，是否合并由负责人决定。

计划按目标和交付物组织，实现方式与内部安排由承担者决定。中期以PPT展示为主，不要求现场操作、录屏、安装专项或稳定性测试。界面主功能前移至中期，PPT结合真实截图、技术设计和案例证据展示进展；中期后主要进行VLM等增强接入。

## VLM与探索范围

VLM在有限主动投入内验证收益、错误与成本，图片范围、模型和请求预算在执行前确定。没有明确收益时保留探索结果，正式软件继续ASR路径。

RL仍采用独立探索定位，保留20—30小时主动投入止损，不扩展为选帧、正文生成等联合策略。实际开展训练前固定数据划分、评价和奖励协议；按真实完成的训练、推理及接入程度记录成果。

## 完成标准

- 主要用户流程可操作，异常和预算状态清楚，导出主要内容一致。
- 真实文档经过内容和排版检查，机器结果与编辑版本来源明确。
- 有使用说明、测试范围和已知问题，安装与系统专项在最终交付准备中处理。
- 代码、说明、截图与实际软件一致，VLM/RL等能力按实现状态说明。
